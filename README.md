# ✈️ TravelTriangle Web Scraping & Data Analytics

## 📊 From Raw Web Data to Business Insights

An end-to-end **Web Scraping & Data Analytics project** based on TravelTriangle tour packages.

This project uses **Python, BeautifulSoup, Pandas, Excel, Matplotlib, and Power BI** to collect, clean, analyze, and visualize real-world travel package data.

> 🚀 **Scrape. Clean. Analyze. Visualize. Decide.**

---

## 🎯 Project Objective

The main objective of this project is to extract meaningful travel package data from TravelTriangle and transform raw web data into useful business insights.

### Key Objectives

- 🌐 Scrape real-world tour package data
- 🧹 Clean and structure the scraped data
- 💰 Analyze package pricing
- 📅 Analyze trip duration
- 🗺️ Compare different destinations
- 📊 Identify pricing and travel patterns
- 💡 Generate actionable business insights
- 📈 Build an interactive Power BI dashboard
